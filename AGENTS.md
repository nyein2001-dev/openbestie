# Open Bestie project rules

- Keep the original thirteen product documents intact. Resolve conflicts using the precedence in the build brief and keep project decisions in `DECISIONS.md`.
- Keep commerce native to Gumroad. The storefront can link to checkout and receipt recovery. Payment data and pack files stay with Gumroad.
- Keep Access verification fail-closed. Local test signing keys, identity routes and fictional listings stay under `test/`.
- Retain each published license at its permanent version URL. Once published, a listing slug stays fixed.
- Use private R2 for versioned, resized previews only. Publish after the owner has independently checked proof, rights, files and native checkout.
- Keep feedback and database exports private. Check the published bundle, browser evidence and acceptance record before releasing changes.
